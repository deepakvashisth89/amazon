This is one of my favorite books.  I have loaned it to others and recommended it several times.  I wanted it on my Kendell so I can always go back to it.  If you like historical romances this is a great book.  It's set in early America so not old England and has a very small touch of history.  I was born in Colorado so I love that it is set here.
