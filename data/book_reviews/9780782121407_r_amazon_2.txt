Well, in one sentence, this is a good book. IF you are only going through the single player game. It gives a brief description of the goal of the level and a map that shows enemy army locations. THen it gives a usually three page detailed walkthrough of each level. It also includes character descriptions, special abilities, ect. The only drawback to this book is it's lack of multiplayer help. All it tells you about that is a description of the various games you can play multiplayer, no tactics except 'Try to flank' or 'Always attack 3 on 1' All in all, it's a good book if you don't want hardcore tactics for multiplayer.
