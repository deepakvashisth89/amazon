The book has a very good introduction to the core of client side javascript.  It is a great reference for coming back to those things that you get kind of rusty on like "regular expressions" and  "creating your own objects". The rest of the book is an  incredibly comprehensive reference which goes into considerable detail.  It's the kind of detail that a compiler manual goes into. I would prefer a  version with indexes like a study bible. If you read most of this book you  wont have to go around copying other peoples code snippets because you'll  be to busy making up your own scripting libraries. I wish that this author  would add about 300 pages on Server Side JScripting and Active Server  Pages.
