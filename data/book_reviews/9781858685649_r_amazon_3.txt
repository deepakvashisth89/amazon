This rune set is quite nice. I haven't really read the book, but from what I have seen so far, it seems helpful and easy to understand. It is reasonably priced, too. The only thing I question is the "special velvet rune pouch." There is a pouch included with my set, but it is certainly not velvet. Maybe some issues of this set had a velvet pouch, but the bag included in the box that I have is a reusable paper type bag. It is the same material found in the reusable bags at grocery stores.
