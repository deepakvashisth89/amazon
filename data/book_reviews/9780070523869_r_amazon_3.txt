This is a great book for getting background information in the world of electricity. I'm only a few chapters into it but I find the material to be relevant despite the fact it was published it the early 80's. I gave it 4 stars, if this was the latest edition I might have given it 5. What I like most about what I have read so far is that it gives great comparisons to help visualize what volt, watts, amps, and other electrical terms are. It also has really good insight on electrical code and how codes are adopted into local ordinances. It is a technical book, a lot of people would probably give it 1 star for this reason. This book is more for detail oriented people that want to know more about wiring from an engineering standpoint.  This is not a book with a lot of illustrations on how to wire a house, if you want a book like that go to your local big box hardware store and get a DIY book on wiring.
