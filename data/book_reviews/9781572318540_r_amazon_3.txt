I have a hard time agreeing with the negative reviewers of this book.  I think that Murray addresses the important issues in CE; namely the key architectural differences between CE and the other Win32 platforms.  As for  a programming reference for CE, well CE uses Win32.  There are plenty of  great Win32 programming references on the shelves right now that can be  used.  Adding yet another targeted to CE would be a waste of Murray's time.
