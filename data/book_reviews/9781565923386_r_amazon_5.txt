I bought this book because of the title and I like O'Reilly books - concise and to the point.This book is well written, concise and to the point. Part I contains an easy to read intro to SNMP. Part II contains some  good info on the NT SNMP services and writing extention agents.HOWEVER,  I was disappointed on the coverage on the management API. Why? Because this  API is obsolete. WinSNMP is now the standard, is available now and will  come with NT 5.0. Now I am not a great fan of the WinSNMP API (you can just  tell it is from Microsoft - badly designed API and more complicated than it  needs to be). Thank goodness there is SNMP++ from HP - an SNMP C++ class  library which is available for free on multiple platforms including NT.  SNMP++ on NT actually uses WinSNMP.I'm glad I did the research on SNMP  packages for NT. If I had followed this book blindly I would have ended up  with a management application that may not run when NT 5.0 comes  out.This would be a great book if it was updated with the WinSNMP and/or  SNMP++ API.Read moreRead less
