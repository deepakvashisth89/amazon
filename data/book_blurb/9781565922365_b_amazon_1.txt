This book is a complete guide to the Internet's Domain Name System (DNS) and the Berkeley Internet Name Domain (BIND) software, the UNIX implementation of DNS. In this second edition, the authors continue to describe BIND version 4.8.3, which is included in most vendor implementations today. In addition, you'll find complete coverage of BIND 4.9.4, the potential future standard. In addition to discussing the basic motivation behind DNS and how to set up the BIND software, this book covers many more advanced topics, including using DNS and BIND on Windows NT systems; how to become a "parent" (i.e., "delegate" the ability to assign names to someone else); how to use DNS to set up mail forwarding correctly; debugging and troubleshooting; and programming.
